
# Blinkit Sales Analytics Dashboard

## Overview

This project is an interactive **Sales Analytics Dashboard** developed in **Power BI** using the Blinkit dataset. The dashboard provides insights into sales performance, outlet distribution, product categories, customer ratings, and inventory trends to support data-driven business decisions.

# Objectives

* Analyze overall sales performance
* Track outlet-wise and item-wise sales trends
* Monitor customer ratings and item visibility
* Compare sales across outlet sizes and locations
* Generate business insights for operational improvement

# Dashboard Insights

* Tier 3 outlets generated the highest sales revenue
* Regular fat products contributed more sales compared to low-fat products
* Fruits, snacks, and household items showed strong sales performance
* Supermarket Type 1 recorded the highest total sales and item count
* Outlet establishment peaked significantly in 2018
